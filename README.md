# GitHubMonitor 桌面版

GitHubMonitor 是一款本地运行的 GitHub 仓库更新监控桌面应用。它可以帮助开发者把多个 GitHub 仓库集中放到一个清爽的工作台中，快速查看最新提交、最新发布、仓库状态变化，以及 GitHub Token 的有效状态。

## 适合谁使用

- 需要长期关注多个 GitHub 仓库的开发者
- 需要跟踪开源项目更新的维护者或使用者
- 需要观察依赖库、SDK、框架版本变化的团队
- 希望用本地桌面工具管理 GitHub 仓库动态的用户

## 核心功能

### 仓库集中关注

GitHubMonitor 支持添加多个 GitHub 仓库，并以卡片形式集中展示。用户可以通过 `owner/repo` 格式或 GitHub 仓库链接添加关注仓库。

每个仓库卡片会展示仓库名称、描述、语言、默认分支、Star、Fork、Issue、归档状态等关键信息，方便快速判断仓库当前状态。

### 最新动态监控

应用会聚合展示仓库的关键更新信息：

- 最新提交
- 最新 Release
- 仓库元数据更新时间
- 默认分支变化
- 仓库活跃或归档状态
- 刷新失败原因

用户无需逐个打开 GitHub 页面，就能快速判断哪些仓库最近有更新。

### 单个刷新与全部刷新

用户可以刷新单个仓库，也可以一键刷新全部关注仓库。刷新完成后，应用会即时反馈处理结果，包括成功数量和失败提示。

### 自动刷新

桌面版支持自动刷新。开启后，GitHubMonitor 会按设定间隔自动检查关注仓库的最新状态，适合长期运行在本地桌面环境中。

### GitHub Token 管理

GitHubMonitor 支持在本地保存 GitHub Token，用于提升 GitHub API 访问限额，或访问授权范围内的私有仓库。

保存 Token 时，应用会自动校验其有效性，并展示：

- Token 是否已配置
- Token 是否有效
- 脱敏后的 Token
- 剩余有效期
- 当前认证状态说明

桌面版通过本地 Tauri 后端请求 GitHub API，可以读取 GitHub 返回的 Token 过期时间信息，从而更准确地显示剩余有效期。

### 搜索关注仓库

当关注仓库较多时，可以使用搜索快速定位目标仓库。搜索内容可匹配仓库名、描述、语言、分支、提交标题、版本信息和错误提示。

### 导入与导出

GitHubMonitor 支持导出当前监控状态，也支持从导出文件恢复关注列表。导出内容会自动移除真实 GitHub Token，只保留安全的脱敏状态，便于备份和迁移。

## 桌面体验

GitHubMonitor 使用浅色蓝紫主题，界面清爽、层次明确。仓库信息以卡片形式展示，常用操作集中在主界面中，适合日常高频使用。

桌面版支持：

- Windows 安装包


## 数据与隐私

GitHubMonitor 采用本地优先设计：

- 仓库关注列表保存在本机
- GitHub Token 保存在本机应用配置中
- 导出文件不会包含真实 Token
- 安装包不携带用户运行数据
- 应用不依赖第三方后端服务

用户的仓库列表、Token 和运行配置都不会被上传到额外服务器。

## 典型使用场景

### 开源项目跟踪

把常用开源项目加入关注列表，集中查看最新提交和 Release，及时掌握项目动态。

### 团队仓库观察

将团队相关仓库集中到一个桌面应用中，快速查看近期变化、刷新失败和仓库状态。

### 依赖版本监控

关注框架、SDK、工具库或基础设施仓库，及时发现新版本发布和重要更新。

### 个人开发工作台

把自己常用、维护或学习的 GitHub 仓库集中管理，减少频繁切换浏览器标签页的成本。
